# geometric_lib

## Общее описание решения

Простая библиотека на Python для подсчёта площади и периметра геометрических фигур.

Библиотека состоит из четырёх модулей:
- `circle.py` — функции для круга.
- `square.py` — функции для квадрата.
- `rectangle.py` — функции для прямоугольника.
- `triangle.py` — функции для треугольника.

В каждом модуле есть две функции: `area` (площадь) и `perimeter` (периметр).
У каждой функции есть docstring с описанием параметров и примером.

### Формулы

| Фигура | Площадь | Периметр |
|--------|---------|----------|
| Круг | S = πr² | P = 2πr |
| Квадрат | S = a² | P = 4a |
| Прямоугольник | S = a · b | P = 2(a + b) |
| Треугольник | S = a · h / 2 | P = a + b + c |

## Описание функций

| Функция | Что делает | Пример |
|---------|------------|--------|
| `circle.area(r)` | площадь круга | `area(2)` → 12.566370614359172 |
| `circle.perimeter(r)` | длина окружности | `perimeter(1)` → 6.283185307179586 |
| `square.area(a)` | площадь квадрата | `area(3)` → 9 |
| `square.perimeter(a)` | периметр квадрата | `perimeter(3)` → 12 |
| `rectangle.area(a, b)` | площадь прямоугольника | `area(2, 3)` → 6 |
| `rectangle.perimeter(a, b)` | периметр прямоугольника | `perimeter(2, 3)` → 10 |
| `triangle.area(a, h)` | площадь треугольника | `area(4, 3)` → 6.0 |
| `triangle.perimeter(a, b, c)` | периметр треугольника | `perimeter(3, 4, 5)` → 12 |

Подробное описание с параметрами — в файле [functions.md](functions.md).

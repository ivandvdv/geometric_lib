# geometric_lib

## Общее описание решения
Библиотека на Python для подсчета площади и периметра фигур:
круг, квадрат, прямоугольник, треугольник.
Каждая фигура находится в отдельном файле, в каждом файле есть
две функции: area (площадь) и perimeter (периметр).

## Описание функций

**circle.py**
- area(r) - площадь круга по радиусу, пример: area(2) примерно 12.57
- perimeter(r) - длина окружности по радиусу, пример: perimeter(1) примерно 6.28

**square.py**
- area(a) - площадь квадрата, пример: area(3) = 9
- perimeter(a) - периметр квадрата, пример: perimeter(3) = 12

**rectangle.py**
- area(a, b) - площадь прямоугольника, пример: area(2, 3) = 6
- perimeter(a, b) - периметр прямоугольника, пример: perimeter(2, 3) = 10

**triangle.py**
- area(a, h) - площадь треугольника по основанию и высоте, пример: area(4, 3) = 6.0
- perimeter(a, b, c) - периметр треугольника, пример: perimeter(3, 4, 5) = 12

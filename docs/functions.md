# Описание функций

В библиотеке есть функции для подсчёта площади и периметра четырёх фигур.

## Circle

Модуль [circle.py](../circle.py) содержит две функции для круга.

### area(r)

Считает площадь круга по радиусу.

Параметры:
- `r` — радиус круга.

Возвращает площадь круга.

Пример:

```python
from circle import area

print(area(2))  # 12.566370614359172
```

### perimeter(r)

Считает длину окружности по радиусу.

Параметры:
- `r` — радиус окружности.

Возвращает длину окружности.

Пример:

```python
from circle import perimeter

print(perimeter(1))  # 6.283185307179586
```

## Square

Модуль [square.py](../square.py) содержит две функции для квадрата.

### area(a)

Считает площадь квадрата по стороне.

Параметры:
- `a` — сторона квадрата.

Возвращает площадь квадрата.

Пример:

```python
from square import area

print(area(3))  # 9
```

### perimeter(a)

Считает периметр квадрата по стороне.

Параметры:
- `a` — сторона квадрата.

Возвращает периметр квадрата.

Пример:

```python
from square import perimeter

print(perimeter(3))  # 12
```

## Rectangle

Модуль [rectangle.py](../rectangle.py) содержит две функции для прямоугольника.

### area(a, b)

Считает площадь прямоугольника по двум сторонам.

Параметры:
- `a` — длина прямоугольника.
- `b` — ширина прямоугольника.

Возвращает площадь прямоугольника.

Пример:

```python
from rectangle import area

print(area(2, 3))  # 6
```

### perimeter(a, b)

Считает периметр прямоугольника по двум сторонам.

Параметры:
- `a` — длина прямоугольника.
- `b` — ширина прямоугольника.

Возвращает периметр прямоугольника.

Пример:

```python
from rectangle import perimeter

print(perimeter(2, 3))  # 10
```

## Triangle

Модуль [triangle.py](../triangle.py) содержит две функции для треугольника.

### area(a, h)

Считает площадь треугольника по основанию и высоте.

Параметры:
- `a` — основание треугольника.
- `h` — высота, опущенная на основание.

Возвращает площадь треугольника.

Пример:

```python
from triangle import area

print(area(4, 3))  # 6.0
```

### perimeter(a, b, c)

Считает периметр треугольника по трём сторонам.

Параметры:
- `a` — первая сторона.
- `b` — вторая сторона.
- `c` — третья сторона.

Возвращает периметр треугольника.

Пример:

```python
from triangle import perimeter

print(perimeter(3, 4, 5))  # 12
```
